Based on code from [Paul Saxman's](https://github.com/saxman) [Genscai](https://github.com/saxman/genscai) repository.

Using LLMs to build knowledge graphs from MIDAS papers.

additional-instructions.ipynb has the demonstration of the knowledge graph exxtraction code.

lib/llm.py is the modified version of the langchain-experimental LLMGraphTransformer class.
